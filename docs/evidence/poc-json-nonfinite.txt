# Evidence — LOG4J-JSON-NONFINITE

Generated 2026-10-23T13:51:53Z on Linux 7.3.0-9-generic x86_64.
java: openjdk version "21.0.12.1" 2026-08-18

One log event is written whose message carries a Double.NaN. The layout
is a JsonTemplateLayout resolving the message as an object, so the
non-finite number reaches JsonWriter.writeNumber(double).

RFC 8259 has no NaN literal. A layout that emits the bare token NaN
produces a document that strict JSON parsers reject.
