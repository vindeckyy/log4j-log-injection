# Evidence — LOG4J-RFC5424-ATTR-DRIFT

Generated 2026-10-23T14:10:10Z on Linux 7.3.0-9-generic x86_64.
java: openjdk version "21.0.12.1" 2026-08-18

One log event is written whose message contains an embedded newline. The
only variable between runs is which Rfc5424Layout attributes the
configuration uses.

  2.x spellings : newLine="true" newLineEscape="&#92;n"
  3.x spellings : includeNL="true" escapeNL="&#92;n"

A correctly configured layout emits ONE syslog record with the newline
escaped. A layout whose newline-escape attribute was silently discarded
emits the newline raw, and the collector sees TWO records.

## D. Which attribute spellings each release accepts

Each attribute is configured on its own and the startup diagnostics are
read back. "rejected" means the layout was built without that
attribute — which is the defect, because the configuration asks for it.
